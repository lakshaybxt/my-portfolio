# PORTFOLIO

A React and TypeScript portfolio built with Vite.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run typecheck
npm run lint
npm run build
```

## Source structure

- `src/components/` contains the page sections.
- `src/data/` contains typed project and blog content.
- `src/pages/Home.tsx` composes the portfolio page.
- `src/assets/` contains the existing styles and images.
